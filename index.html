Manuais rápidos

Instalação e primeiros passos

Abra o guia do produto que você quer usar.

AndroidInstalar o APK
  1. Baixe o APK e abra o arquivo na notificação ou na pasta Downloads.
  2. Se o Android pedir, autorize temporariamente a instalação para o navegador usado.
  3. Confirme a instalação, abra o app e entre com sua conta ou crie uma nova.

Mantenha o Play Protect ativo. Se o Android apontar um problema, interrompa a instalação e fale com o suporte.

Voltar ao download do APK
UniversalInstalar pelo navegador
  1. Abra o Z-Link Talk Universal no navegador.
  2. No iPhone, use o Safari e procure Adicionar à Tela de Início no menu de compartilhamento. No Android ou PC, procure Instalar app ou Adicionar à tela inicial no menu do navegador.
  3. Abra o atalho criado e entre com sua conta do Z-Link Talk.

Os nomes das opções variam conforme o navegador.

Windows e Z-Link V6Configurar o Gateway Controller
  1. Conecte a interface Z-Link V6 ao computador pela porta USB marcada HOST.
  2. Abra o Z-Link Gateway Controller.exe no Windows. Tenha o Zello Desktop ou o EchoLink Desktop instalado separadamente, conforme o programa que vai usar.
  3. Confira os dispositivos de entrada e saída de áudio e faça um teste de recepção e transmissão na sua configuração.

Se a interface não for reconhecida, reconecte o USB e confira se os dispositivos aparecem no Windows. Se ainda precisar de ajuda, envie ao suporte a versão do Windows e o nome do programa que está usando.

Dúvidas e suporte técnico

Encontre respostas rápidas sobre instalação, conta, áudio e integração com a Z-Link V6.

Qual versão devo usar no computador?

Para conversar nos canais do Z-Link Talk, use a versão Universal. Para usar a interface Z-Link V6 com Zello Desktop ou EchoLink Desktop, use o Gateway Controller.

O Gateway Controller já vem com Zello e EchoLink?

Não. O Gateway Controller permite usar a interface Z-Link V6 com esses programas, que são instalados separadamente no Windows.

Preciso de contribuição ou plano empresarial para usar o Gateway Controller?

Não. Para usar a Z-Link V6 com Zello Desktop ou EchoLink Desktop no Windows, não é necessário ter contribuição ativa nem plano empresarial do Z-Link Talk. Essas opções se aplicam apenas ao PTT Online do Z-Link Talk.

O download ou a instalação do APK falhou. O que faço?

Tente o download direto. Abra o APK somente após a conclusão do download. Se o Android bloquear a instalação, veja o guia de instalação.

O link de renovação não chegou. O que faço?

Confira a caixa de entrada e a pasta Spam. Use o e-mail cadastrado e verificado no Z-Link Talk. Se houver limite de solicitações, aguarde o prazo mostrado antes de tentar de novo.

Preciso reinstalar o aplicativo para renovar o PTT Online?

Não. Abra Minha Conta e Renovação, solicite o link e siga as orientações recebidas por e-mail.

O PTT funciona, mas ninguém ouve minha voz. O que devo conferir?

No Z-Link Talk, confira a permissão do microfone, a entrada de áudio selecionada e se você está no canal certo. Com a Z-Link V6, confirme também se o dispositivo de entrada está selecionado no Windows e no Zello ou EchoLink.

Já contribuí e ainda não consigo acessar os canais. O que faço?

Confira se você entrou com o mesmo e-mail usado na contribuição e veja a situação da conta no aplicativo. Se a contribuição ainda não aparecer, fale com o suporte antes de fazer um novo pagamento.

Minha Conta e Renovação

Informe o e-mail cadastrado no Z-Link Talk para solicitar seu link seguro de renovação. Você receberá uma confirmação quando a mensagem for aceita para envio.

O link será enviado somente para contas aptas à renovação e com e-mail verificado. Confira também a pasta Spam.

Baixar Z-Link Talk?

O APK será baixado com acompanhamento do progresso. A instalação não ativa automaticamente os canais online: o acesso depende de cadastro e contribuição vigente.
